# YM Player Mobile

The phone version of YM Player: an Xtream Codes IPTV player for Android phones.

- Netflix-style portrait app: Home, Live TV, Movies, Series and Search along the bottom
- Turns to landscape when you start watching, with touch controls
  (tap for controls, double-tap left/right to skip −5 s / +10 s, drag to scrub,
  swipe up/down to change channel on Live TV)
- VLC for Live TV, the Android player for movies and series
- Netflix UK Top 10 rows, Continue Watching, favourites, multiple accounts, light/dark theme

## Install

Download the latest APK on your phone:
https://github.com/YousufMiahh/YMPlayer-Mobile/releases/latest/download/YMPlayerMobile.apk

Every push to `main` builds a new release with GitHub Actions.
